# ⚡ BayFlow (베이플로우)
> 이베이 역직구 셀러를 위한 올인원 자동화 모바일 웹앱 (PWA)

포켓몬 카드, 굿즈 등 해외 역직구 판매자를 위해 주문 수집부터 우체국 K-Packet 송장 자동 등록, 관심 고객 오퍼 관리, 공식 수수료 반영 마진 계산기, 국내 시세차익 자동 소싱 레이더까지 한 화면에서 '버튼 딸깍'으로 처리하는 대시보드입니다.

---

## 📱 주요 기능

1. **📦 주문 관리 & 우체국 K-Packet 송장 원클릭 등록**
   - eBay에서 결제 완료된 신규 주문을 실시간 감지
   - [우체국 API 송장 자동 발급] 버튼 하나로 K-Packet 등기번호(LP...KR) 채번 및 eBay 주문에 자동 송장 입력 완료
2. **🏷️ 오퍼 & 구매자 CS 관리**
   - 관심 등록 고객 대상 단체 할인 오퍼(Send Offer) 현황 및 만료 타이머 확인
   - 바이어 해외 문의(스캘핑, 배송 문의 등) 현황 확인 및 빠른 영문 응대
3. **🧮 공식 규정 100% 반영 실전 마진 계산기**
   - 판매가, 매입원가, 환율, 배송비 입력 시 실시간 통장 순입금액 계산
   - eBay 기본 수수료(13.25% + $0.40) + 한국 셀러 해외수수료(1.45%) + 미국 구매자 세금(Sales Tax 8%) 연동 수수료 + 페이오니아 인출수수료(2%) 자동 공제 반영
4. **🎯 시세차익 자동 소싱 레이더 (Arbitrage Radar)**
   - 국내 마켓(번개장터, 중고나라 등) 매물 시세와 eBay 최근 거래가(Sold)를 실시간 매칭
   - 순마진 30% 이상 남는 상품만 자동 추천 및 원클릭 리스팅 지원

## 🚀 1분 만에 무료 배포 & 폰에 앱 설치하기

### 1단계: Vercel에 1분 무료 배포
1. 깃허브(GitHub)에 새 리포지토리(예: `bayflow`)를 생성하고 `bayflow/` 폴더 안의 파일들을 푸시합니다.
2. [Vercel.com](https://vercel.com)에 로그인 후 **[Add New Project]**에서 해당 깃허브 리포지토리를 선택하고 **Deploy**를 누릅니다.
3. 30초 후 나만의 고유 주소(예: `https://bayflow.vercel.app`)가 생성됩니다.

### 2단계: 갤럭시 스마트폰에 '진짜 앱'으로 설치하기
1. 스마트폰(삼성 인터넷 또는 크롬)에서 생성된 Vercel 웹 주소로 접속합니다.
2. 상단에 뜨는 **[앱 설치]** 배너를 누르거나, 브라우저 우측 하단 메뉴(≡)에서 **[홈 화면에 추가]**를 누릅니다.
3. 스마트폰 홈 화면에 **⚡ BayFlow** 앱 아이콘이 생성되며, 실행 시 주소창 없는 전체 화면 네이티브 앱으로 동작합니다!

## 💡 B2B SaaS 사업화 로드맵
- **1단계 (자체 사용 검증)**: 동욱님이 직접 쓰면서 하루 배송/송장 업무 1~2시간 절감
- **2단계 (베타 테스터 모집)**: 이베이 셀러 커뮤니티에 무료 체험 링크 공유 후 피드백 수집
- **3단계 (월 구독 유료화)**: 토스페이먼츠/Stripe 연동하여 월 29,000원 구독형 이커머스 솔루션으로 런칭
